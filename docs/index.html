BuriedCaches

Treasure hidden in the act of mining itself.

Paper plugin Vanilla loot tables Source on GitHub

What it does

While a player mines natural stone and ore underground, every block they break carries a small chance of uncovering a Buried Cache — a barrel that appears in the mined space, filled from a vanilla loot table, and locked to its finder for a short window. No structures to hunt, no maps, no commands: the treasure is in the digging you were already doing.

Rarity escalates the moment. A Common find chimes softly for the finder. A Legendary find erupts in totem particles and fireworks, and the whole server hears about it.

The tiers

Common
weight 60 · abandoned_mineshaft

Rails, bread, name tags, the occasional golden apple. A pleasant surprise.

Rare
weight 28 · buried_treasure

Iron, gold, TNT — and a shot at a heart of the sea.

Epic
weight 10 · ancient_city

Enchanted books, disc fragments, echo shards. Broadcast to the server.

Legendary
weight 2 · end_city_treasure

Enchanted diamond gear. Totem burst, fireworks, server-wide announcement.

Every tier is defined in the config — rename them, reweight them, point them at any loot table (vanilla or datapack-provided), or add new ones.

Fairness & anti-farm

Pity timer

A guaranteed find after 450 eligible blocks (configurable). Nobody stays unlucky forever.

Placed blocks never count

Player-placed stone and ore is recorded in chunk persistent data and excluded — surviving restarts, pistons, and explosions. Place-and-break farms don't work.

Cooldown

A per-player cooldown (4 minutes by default) stops hammers and beacon-haste miners from chaining finds.

Finder ownership

For 30 seconds only the finder can open or break the barrel — and it can't be hoppered or exploded out from under them.

Survival only

Creative and spectator breaks don't roll (configurable), and the mechanic stays below Y=64.

No leftovers

Emptied cache barrels remove themselves. If the mined space closes before the barrel appears, the loot is delivered straight to the finder.

Installation

  1. Download buried-caches-<version>.jar from the releases page, or build it from source.
  2. Drop the jar into your server's plugins/ folder.
  3. Restart. The default config.yml is generated on first run.

Requires Paper (or a fork) matching the api-version declared in plugin.yml.

Commands & permissions

CommandPermissionWhat it does
/buriedcaches stats [player] buriedcaches.stats (everyone) Lifetime finds by tier. Viewing another player requires admin.
/buriedcaches status [player] buriedcaches.admin (op) Blocks since last find, cooldown remaining, forced flag.
/buriedcaches force <player> buriedcaches.admin Guarantees a find on that player's next eligible block.
/buriedcaches reset <player> buriedcaches.admin Resets roll progress (lifetime stats are kept).
/buriedcaches reload buriedcaches.admin Reloads the configuration in place.

Alias: /bcaches

Configuration reference

Trigger

trigger:
  # Only count real survival mining.
  require-survival: true

  # A treasure cannot roll before this many eligible natural blocks.
  minimum-blocks: 40

  # Roughly one successful roll per 250 eligible blocks after the minimum.
  chance-per-block: 0.004

  # Guarantees that a genuinely unlucky player eventually finds one.
  pity-after-blocks: 450

  # Prevents a hammer or fast miner from receiving several treasures at once.
  cooldown-seconds: 240

  # Keeps the mechanic underground.
  maximum-y: 64

  allowed-environments: [NORMAL]
  disabled-worlds: []

  # Blocks that count toward a roll. Placing one records its location
  # in the chunk, so breaking a placed block never counts.
  eligible-materials:
    - STONE
    - DEEPSLATE
    - TUFF
    # ...granite, diorite, andesite, and every overworld ore variant

Ownership

ownership:
  # Only the finder can open, break, hopper, or explode the barrel during this window.
  lock-seconds: 30

  # Removes the generated barrel once its inventory is empty.
  remove-empty-barrels: true

Tiers

A successful roll picks one enabled tier by weight, then asks the configured loot table to fill the barrel. celebration picks the effect bundle: STANDARD (finder-only chime), GRAND (enchanting-table swirl nearby players hear too), or MYTHIC (totem burst and fireworks the whole cave hears). broadcast announces the find to every online player. 

tiers:
  legendary:
    enabled: true
    display-name: Legendary
    color: GOLD
    weight: 2
    loot-table: minecraft:chests/end_city_treasure
    celebration: MYTHIC
    broadcast: true

Loot fallback

loot:
  # If a loot table returns nothing (another plugin or datapack changed it),
  # a successful find still pays out.
  empty-fallback-material: GOLD_INGOT
  empty-fallback-minimum: 2
  empty-fallback-maximum: 5

Building from source

git clone https://github.com/ThConMan/buried-caches.git
cd buried-caches
./gradlew build

The jar lands in build/libs/. Gradle resolves the JDK 25 toolchain automatically. The test suite runs as part of build.
